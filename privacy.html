隐私政策

1. 我们收集的信息

本站无需注册。仅当您主动订阅邮件周刊时，我们收集您填写的邮箱地址。为防止滥用，订阅接口会临时使用请求 IP 做频率限制（仅保存在服务器内存中，不做持久存储）。

托管于 Vercel 的站点版本使用 Vercel Web Analytics 统计匿名访问量（不使用 Cookie、不识别个人身份）。GitHub Pages 版本不加载该统计脚本。

2. 使用目的

邮箱仅用于向您发送 AI 工具周刊，不用于其他目的，不出售、不出租给任何第三方。

3. 存储与跨境传输

邮箱地址存储于邮件服务商 Resend（服务器位于境外）。订阅即表示您单独同意将邮箱地址提供给该境外服务商用于发送周刊。网站托管服务商 Vercel、GitHub 同样位于境外。

4. 保存期限

保存至您退订为止；退订后我们将停止发送并在合理期限内删除您的邮箱。

5. 您的权利与退订

您可随时退订：每封周刊邮件均提供退订链接；也可在下方输入邮箱直接退订。如需查询、更正或删除数据，请通过 GitHub Issues 联系（请勿在公开 Issue 中填写邮箱）。

6. 未成年人

本站不面向未满 14 周岁的未成年人收集信息。

7. 变更

本政策变更将在本页更新并注明日期。
